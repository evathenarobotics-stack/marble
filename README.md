This is my final design, I slightly strayed from the original plan I had by removing the slope thingeys just because it didn’t fit. This was largely inspired by the references that were provided because I really liked that double path that was on the first picture so I wanted to incorporate it. However, unlike what my idea reel announced, I did not end up doing anything nearly similar to what my AP Physics project was like. That one was way simpler and didn’t have any of these trials.

So, basically, you drop a marble into the funnel and it slides down this Archimedes like spiral and then enters a long slide. Then, it drops into a double funnel system and will either slide down right or left, with each side having a different path. One path brings it down another long slope into a plinko path, and the other brings it down a set of stairs. Finally, the marble lands in a little dish at the bottom of the trails.
